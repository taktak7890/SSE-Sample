Server-Sent Events (SSE) の仕組み

1. 単方向ストリーミング: サーバーからクライアントへデータをプッシュ（WebSocketと違い通常のHTTP/1.1・HTTP/2上で動作）。
2. 自動再接続 (Built-in Reconnection): ネットワーク断時、ブラウザが retry: ms 設定に従い自動で再接続します。
3. Last-Event-ID による状態復元: 切断直前に受け取った id を Last-Event-ID ヘッダーとして自動再送し、データの抜け漏れを防止します。
4. イベント名のルーティング: event: chat のように名前をつけることで、クライアント側で addEventListener('chat', ...) と型安全に購読可能です。
